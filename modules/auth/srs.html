1. Introduction

1.1 Purpose

This document defines the software requirements for the Authentication module. It covers user registration, login, session management, verification, password management, and role-based access control.

1.2 Scope

User accounts, login (email/phone + password), sessions, roles, email/phone verification, password reset, and RBAC.

1.3 Module Dependencies

None (standalone module).

3. Functional Requirements

3.1 UC-01: User Registration

FieldValue
Requirement IDsAUTH-FR-001
ActorUser
PreconditionUser is not authenticated
PostconditionUser account created, verification sent via RabbitMQ

Main Flow

  1. User provides email (or phone) + password + name
  2. System validates input format
  3. System checks idempotency key in Redis
  4. System creates user record in auth_users
  5. System creates account record in auth_accounts
  6. System publishes verification event to RabbitMQ
  7. System returns success response

3.12 UC-12: Request Account Verification

FieldValue
Requirement IDsAUTH-FR-012
ActorUser / System

Main Flow

  1. System checks Redis idempotency key: idempotency:{user_id}:{channel}
  2. If key exists: return "already sent" (idempotent response)
  3. If no key: set key in Redis with 5-min TTL
  4. System generates verification token/OTP
  5. System stores token in auth_verification
  6. System publishes event to RabbitMQ verification.{channel}
  7. System returns success immediately
