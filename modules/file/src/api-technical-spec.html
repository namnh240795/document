1. Overview

1.1 Requirements Addressed

SRS RequirementAPI Endpoint(s)
FR-001 Upload FilePOST /files/presigned-url, POST /files/confirm
FR-002 Download FileGET /files/:id/download-url
FR-003 List FilesGET /files
FR-004 Delete FileDELETE /files/:id
FR-005 File Access ControlAll endpoints (middleware)

1.2 Authentication

All endpoints require authentication via:

  • Bearer Token — Authorization: Bearer <token>
  • API Key Cookie — apiKeyCookie

Additionally, file access is validated against ownership or organization membership (RBAC).

1.3 Endpoint Summary

MethodPathDescriptionAuth Required
POST/files/presigned-urlGenerate presigned upload URLYes
POST/files/confirmConfirm file upload completionYes
GET/files/:id/download-urlGenerate presigned download URLYes
GET/filesList files with filtering and paginationYes

4. File Endpoints

4.1 Upload File (Presigned URL)

POST /files/presigned-url FR-001

Generate a presigned URL for direct client upload to S3. Creates a file record with status TEMP.

Request:

{
  "original_name": "my-resume.pdf",
  "mime_type": "application/pdf",
  "category": "RESUME",
  "employer_id": "acme-corp-uuid"
}

Request Fields:

FieldTypeRequiredDescription
original_namestringYesOriginal filename (max 500 chars)
mime_typestringYesMIME type (must match allowed types for category)
categorystring (enum)YesRESUME, AVATAR, COMPANY_DOC, JOB_ATTACHMENT, OTHER
employer_idstring (UUID)NoEmployer ID for organization-scoped files

Validation Rules:

CategoryAllowed MIME TypesMax Size
RESUMEapplication/pdf, application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document10 MB
AVATARimage/jpeg, image/png, image/webp5 MB
COMPANY_DOCimage/*, application/pdf10 MB
JOB_ATTACHMENTapplication/pdf, application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document, image/*10 MB
OTHER*10 MB

Response 200:

{
  "success": true,
  "data": {
    "upload_url": "https://bucket.s3.amazonaws.com/acme/user-123/RESUME/a1b2c3d4-resume.pdf?X-Amz-Algorithm=...",
    "file_id": "file-uuid-123",
    "storage_key": "acme/user-123/RESUME/a1b2c3d4-resume.pdf",
    "expires_at": "2026-08-17T11:00:00Z"
  }
}

Client Upload (PUT to presigned URL):

PUT {upload_url}
Content-Type: application/pdf
Body: <binary file data>

4.2 Confirm Upload

POST /files/confirm FR-001

Confirm that a file upload has completed successfully. Updates file status from TEMP to ACTIVE.

Request:

{
  "file_id": "file-uuid-123"
}

Request Fields:

FieldTypeRequiredDescription
file_idstring (UUID)YesFile ID returned from presigned-url endpoint

Response 200:

{
  "success": true,
  "data": {
    "id": "file-uuid-123",
    "employer_id": "acme-corp-uuid",
    "user_id": "user-uuid-456",
    "original_name": "my-resume.pdf",
    "storage_key": "acme/user-123/RESUME/a1b2c3d4-resume.pdf",
    "bucket_name": "job-portal-files",
    "mime_type": "application/pdf",
    "file_size": 524288,
    "category": "RESUME",
    "is_public": false,
    "status": "ACTIVE",
    "created_at": "2026-08-17T10:45:00Z",
    "updated_at": "2026-08-17T10:46:00Z"
  }
}

Error 404 — File not found or already confirmed:

{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "File not found or already confirmed"
  }
}

4.3 Get Download URL

GET /files/:id/download-url FR-002

Generate a presigned download URL for a file. Validates access control before generating URL.

Path Parameters:

ParameterTypeDescription
idstring (UUID)File ID

Response 200:

{
  "success": true,
  "data": {
    "download_url": "https://bucket.s3.amazonaws.com/acme/user-123/RESUME/a1b2c3d4-resume.pdf?X-Amz-Algorithm=...",
    "expires_at": "2026-08-17T11:00:00Z",
    "file_name": "my-resume.pdf"
  }
}

Error 403 — Access denied:

{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "You do not have permission to access this file"
  }
}

Error 404 — File not found:

{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "File not found"
  }
}

4.4 List Files

GET /files FR-003

List files with optional filtering by user, employer, and category. Supports pagination.

Query Parameters:

ParameterTypeRequiredDescription
user_idstring (UUID)NoFilter by user ID (defaults to current user)
employer_idstring (UUID)NoFilter by employer ID
categorystring (enum)NoFilter by category (RESUME, AVATAR, COMPANY_DOC, JOB_ATTACHMENT, OTHER)
pageintegerNoPage number (default: 1)
limitintegerNoItems per page (default: 20, max: 100)

Example Request:

GET /files?category=RESUME&page=1&limit=10

Response 200:

{
  "success": true,
  "data": {
    "files": [
      {
        "id": "file-uuid-123",
        "employer_id": "acme-corp-uuid",
        "user_id": "user-uuid-456",
        "original_name": "my-resume.pdf",
        "storage_key": "acme/user-123/RESUME/a1b2c3d4-resume.pdf",
        "bucket_name": "job-portal-files",
        "mime_type": "application/pdf",
        "file_size": 524288,
        "category": "RESUME",
        "is_public": false,
        "status": "ACTIVE",
        "created_at": "2026-08-17T10:45:00Z",
        "updated_at": "2026-08-17T10:45:00Z"
      }
    ],
    "total": 42,
    "page": 1,
    "limit": 10
  }
}

4.5 Delete File

DELETE /files/:id FR-004

Soft-delete a file. Sets status to DELETED and emits event for asynchronous S3 cleanup.

Path Parameters:

ParameterTypeDescription
idstring (UUID)File ID

Response 200:

{
  "success": true,
  "message": "File deleted successfully"
}

Error 403 — Not authorized:

{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "You can only delete your own files"
  }
}

Error 404 — File not found:

{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "File not found"
  }
}
