3. Endpoints

3.1 Log Queries

GET /logs FR-002

Query logs with filters.

Query Parameters:

ParameterTypeDescription
levelstringFilter by level: debug, info, warn, error
sourcestringFilter by source service (auth, sms, etc.)
actionstringFilter by action (login, register, etc.)
userIdstringFilter by user ID
traceIdstringFilter by trace ID
fromdatetimeStart time (ISO 8601)
todatetimeEnd time (ISO 8601)
searchstringFull-text search in message
pageintPage number (default: 1)
limitintResults per page (default: 20, max: 100)

Response 200:

{
  "success": true,
  "data": [
    {
      "eventId": "evt-uuid-123",
      "source": "auth",
      "level": "info",
      "action": "login",
      "message": "User logged in successfully",
      "userId": "user-uuid-456",
      "traceId": "trace-uuid-789",
      "timestamp": "2026-07-24T10:30:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 1500,
    "totalPages": 75
  }
}

GET /logs/:eventId

Get log event by ID.

Response 200:

{
  "success": true,
  "data": {
    "eventId": "evt-uuid-123",
    "source": "auth",
    "level": "info",
    "action": "login",
    "message": "User logged in successfully",
    "input": "{\"email\":\"user@example.com\"}",
    "output": "{\"userId\":\"123\",\"token\":\"...\"}",
    "userId": "user-uuid-456",
    "traceId": "trace-uuid-789",
    "timestamp": "2026-07-24T10:30:00Z"
  }
}

3.2 Analytics

GET /logs/analytics FR-003

Get log analytics aggregations.

Query Parameters:

ParameterTypeDescription
fromdatetimeStart time
todatetimeEnd time
intervalstringAggregation interval: minute, hour, day

Response 200:

{
  "success": true,
  "data": {
    "totalEvents": 150000,
    "byLevel": {
      "info": 120000,
      "warn": 25000,
      "error": 5000
    },
    "bySource": {
      "auth": 100000,
      "sms": 50000
    },
    "timeline": [
      { "timestamp": "2026-07-24T10:00:00Z", "count": 500 },
      { "timestamp": "2026-07-24T11:00:00Z", "count": 750 }
    ]
  }
}

3.3 Real-time Streaming

WebSocket /ws/logs FR-004

Real-time log streaming via WebSocket.

Connection:

ws://api.example.com/ws/logs?token=jwt_token&level=error&source=auth

Message Format:

{
  "type": "log",
  "data": {
    "eventId": "evt-uuid-123",
    "source": "auth",
    "level": "error",
    "message": "Login failed",
    "timestamp": "2026-07-24T10:30:00Z"
  }
}
