1.2 API Principles

  • RESTful design
  • JSON request/response
  • Versioned via URL path (/v1/)
  • Stateless (JWT authentication)
  • Role-based endpoints: /candidate/, /hr/, /employer/

1.3 Authentication

All endpoints require JWT Bearer token unless marked as Public. The JWT includes the user's role.

Authorization: Bearer <access_token>

// JWT Payload includes:
{
  "sub": "user_id",
  "email": "user@example.com",
  "role": "candidate" | "hr" | "employer"
}

2. Response Format

{
  "success": true,

5. Endpoints

5.1 Authentication (All Roles)

POST /recr/auth/register (Public) FR-001, FR-016

Register new user as candidate, HR, or employer.

Note: All users can optionally purchase subscription (POST /recr/subscription/purchase) for premium features.

Request:

{
  "email": "john@example.com",
  "password": "securepassword123",
  "full_name": "John Doe",
  "phone": "0901234567",
  "role": "candidate",
  // For employer only:
  "company_name": "Tech Corp",
  "industry": "Technology"
}

Response 201:

{
  "success": true,
  "data": {
    "id": 1,
    "email": "john@example.com",
    "role": "candidate",
    "token": "jwt_token_here"
  }
}

POST /recr/auth/login (Public) FR-002

Login with email/password. Returns JWT with role claim.

Request:

{
  "email": "john@example.com",
  "password": "securepassword123"
}

Response 200:

{
  "success": true,
  "data": {
    "id": 1,
    "email": "john@example.com",
    "role": "candidate",
    "token": "jwt_token_here"
  }
}

5.2 Candidate Endpoints

GET /recr/jobs FR-003

Browse job listings. Public endpoint (no auth required).

Query Params: search, location, salary_min, employment_type, page, limit

POST /recr/applications FR-004

Submit job application. Requires candidate role.

Request:

{
  "job_id": 1,
  "cover_letter": "I am interested in this position..."
}

GET /recr/candidate/applications FR-005

View my applications. Requires candidate role.

PATCH /recr/candidate/profile FR-006

Update profile. Requires candidate role.

POST /recr/candidate/resume FR-007

Upload resume. Requires candidate role. Max 10MB.

POST /recr/candidate/reviews/jobs FR-030

Review a job. Requires candidate role. Must have applied to the job.

Request:

{
  "job_id": 1,
  "overall_rating": 4,
  "work_life_balance": 5,
  "compensation": 3,
  "career_growth": 4,
  "company_culture": 4,
  "title": "Great work environment",
  "description": "Good company culture but salary could be better...",
  "is_anonymous": false
}

GET /recr/candidate/reviews/jobs/:jobId FR-030

Get reviews for a job. Public endpoint.
