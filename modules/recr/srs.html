1. Introduction

1.1 Purpose

This document defines the software requirements for the Recruitment module of the HR Management System.

1.2 Scope

The Recruitment module manages the end-to-end hiring process with three distinct user roles: Candidate (job seekers), HR (recruitment team), and Employer (companies posting jobs). Each role has specific permissions and workflows.

1.3 Module Dependencies

3. Functional Requirements

3.1 Candidate Requirements

Req ID Module Requirement Use Case Priority Description
FR-001 RECR Candidate Registration UC-01 High Candidates can register accounts with email, password, and basic profile information
FR-002 RECR Candidate Login UC-02 High Candidates can log in with email/password and receive JWT token
FR-003 RECR Browse Jobs UC-03 High Candidates can browse and search job listings with filters (location, salary, type)
FR-004 RECR Submit Application UC-04 High Candidates can submit applications with resume, cover letter for specific jobs
FR-005 RECR View Application Status UC-05 High Candidates can track their application progress through recruitment stages
FR-006 RECR Update Profile UC-06 Medium Candidates can update their profile, skills, and experience
FR-007 RECR Upload Resume UC-07 High Candidates can upload and manage their resume files (PDF, DOCX)

3.2 HR Requirements

Req ID Module Requirement Use Case Priority Description
FR-008 RECR Review Applications UC-08 High HR can review applications, filter by job, status, and candidate qualifications
FR-009 RECR Screen Candidates UC-09 High HR can screen candidates and move them through recruitment stages
FR-010 RECR Schedule Interview UC-10 High HR can schedule interviews with date/time, location, meeting link
FR-011 RECR Evaluate Candidate UC-11 High HR can submit evaluations with scores and recommendations
FR-012 RECR Send Offer UC-12 High HR can create and send offer letters with salary and benefits
FR-013 RECR Reject Candidate UC-13 High HR can reject candidates with optional rejection reason
FR-014 RECR Track Pipeline UC-14 High HR can view recruitment pipeline with candidate counts per stage
FR-015 RECR Generate Reports UC-15 Medium HR can generate recruitment metrics and analytics reports

3.3 Employer Requirements

Req ID Module Requirement Use Case Priority Description
FR-016 RECR Employer Registration UC-01 High Employers can register company accounts with company details
FR-017 RECR Post Job UC-16 High Employers can create job listings with requirements and salary range
FR-018 RECR Manage Job Listings UC-17 High Employers can edit, close, or archive their job listings
FR-019 RECR View Applicants UC-18 High Employers can view applicants for their posted jobs
FR-020 RECR Approve Job Posting UC-19 Medium Employers can submit jobs for HR approval before publishing
FR-021 RECR View Analytics UC-20 Medium Employers can view recruitment analytics for their job postings
