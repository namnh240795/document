SRS RequirementAPI Endpoint(s)

1.2 API Principles

  • RESTful design
  • JSON request/response
  • Versioned via URL path (/v1/)
  • Stateless (JWT authentication via Better Auth)

1.3 Authentication

All endpoints require JWT Bearer token unless marked as Public.

Authorization: Bearer <access_token>

2. Response Format

2.1 Success Response

{
  "success": true,
  "data": { ... },
  "meta": {
    "requestId": "req-abc-123",
    "timestamp": "{{DATE}}T10:30:00Z"
  }
}

2.2 Error Response

{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid input data",
    "details": [
      { "field": "email", "message": "Invalid email format" }
    ]
  }
}
