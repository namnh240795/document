1. Overview

1.1 Requirements Addressed

SRS RequirementAPI Endpoint(s)
FR-001 User RegistrationPOST /auth/register
FR-002 User LoginPOST /auth/login
FR-003 View ProductsGET /products, GET /products/:id
FR-004 Create OrderPOST /orders
FR-005 Process PaymentPOST /payments
FR-006 Manage UsersGET /users, GET/PUT /users/:id
FR-007 Generate ReportsGET /reports/sales
NFR-003 AuthenticationAll endpoints (JWT Bearer)
NFR-004 AuthorizationRole-based access per endpoint

1.1 API Principles

  • RESTful design
  • JSON request/response
  • Versioned via URL path (/v1/, /v2/)
  • Stateless (JWT authentication)
  • Idempotent PUT/DELETE operations

1.2 Authentication

All endpoints require JWT Bearer token unless marked as Public.

Authorization: Bearer <access_token>

1.3 Common Headers

HeaderValueRequired
Content-Typeapplication/jsonYes (for body)
AuthorizationBearer <token>Yes
X-Request-IDUUIDNo (auto-generated)
Accept-Languageen / viNo (default: en)

5. Endpoints

5.1 Auth

POST /auth/login (Public) FR-002

User login. Resolves: FR-002 User Login requirement

Request:

{
  "email": "user@example.com",
  "password": "securepassword"
}

Response 200:

{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOiJSUzI1NiIs...",
    "refreshToken": "dGhpcyBpcyBhIHJlZnJl...",
    "expiresIn": 900,
    "tokenType": "Bearer",
    "user": {
      "id": 1,
      "email": "user@example.com",
      "role": "customer"
    }
  }
}

Error 401:

{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid email or password"
  }
}

POST /auth/register (Public) FR-001

Create new account. Resolves: FR-001 User Registration requirement

Request:

{
  "email": "newuser@example.com",
  "password": "securepassword",
  "fullName": "John Doe",
  "phone": "+84901234567"
}

Response 201:

{
  "success": true,
  "data": {
    "id": 2,
    "email": "newuser@example.com",
    "fullName": "John Doe",
    "role": "customer",
    "status": "active",
    "createdAt": "2024-01-15T10:30:00Z"
  }
}

POST /auth/refresh (Public)

Refresh access token

Request:

{
  "refreshToken": "dGhpcyBpcyBhIHJlZnJl..."
}

Response 200:

{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOiJSUzI1NiIs...",
    "expiresIn": 900
  }
}

5.4 Orders

POST /orders (Requires: customer) FR-004

Request:

{
  "items": [
    { "productId": 1, "quantity": 2 },
    { "productId": 3, "quantity": 1 }
  ],
  "shippingAddressId": 1,
  "paymentMethod": "credit_card",
  "notes": "Please deliver in the morning"
}

Response 201:

{
  "success": true,
  "data": {
    "id": 1,
    "orderNumber": "ORD-20240115-001",
    "status": "pending",
    "items": [
      { "productId": 1, "quantity": 2, "unitPrice": 299000, "subtotal": 598000 },
      { "productId": 3, "quantity": 1, "unitPrice": 149000, "subtotal": 149000 }
    ],
    "subtotal": 747000,
    "taxAmount": 74700,
    "shippingFee": 30000,
    "totalAmount": 851700,
    "paymentMethod": "credit_card",
    "createdAt": "2024-01-15T10:30:00Z"
  }
}

Error 422:

{
  "success": false,
  "error": {
    "code": "UNPROCESSABLE",
    "message": "Insufficient stock for product ID 1",
    "details": [
      { "productId": 1, "available": 1, "requested": 2 }
    ]
  }
}

GET /orders (Requires: customer own, admin/staff all) FR-004

Query Parameters:

ParameterTypeDefaultDescription

fromdate-Start date (YYYY-MM-DD)
todate-End date (YYYY-MM-DD)

    "totalPages": 8,

9. SDK & Integration Examples

cURL

# Login
curl -X POST https://api.example.com/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"pass123"}'

# Get products (with token)
curl https://api.example.com/v1/products \
  -H "Authorization: Bearer <token>"

JavaScript (fetch)

const response = await fetch('/api/v1/orders', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    items: [{ productId: 1, quantity: 2 }],
    shippingAddressId: 1,
    paymentMethod: 'credit_card'
  })
});
const data = await response.json();
