4. Functional Requirements Detail

Req ID Module Requirement Use Case Priority Description
FR-001 AUTH User Registration UC-01 High System shall allow users to register with email and password
FR-002 AUTH User Login UC-01 High System shall authenticate users via email/password
FR-003 PROD View Products UC-02 High System shall display product catalog with search and filter
FR-004 ECOM Create Order UC-03 High System shall allow users to checkout with selected items
FR-005 PAY Process Payment UC-03 High System shall integrate with payment gateway for transactions
FR-006 AUTH Manage Users UC-04 Medium Admin shall be able to create, edit, deactivate users
FR-007 ECOM Generate Reports UC-05 Medium System shall generate sales and user reports
FR-008 WAL Wallet Top-up UC-06 High System shall allow users to top-up wallet via bank transfer or credit card
FR-009 WAL Wallet Payment UC-03 High System shall allow users to pay orders using wallet balance
FR-010 WAL Wallet Transfer UC-07 Medium System shall allow users to transfer balance to other users
FR-011 PAY Refund Payment UC-08 Medium System shall process refunds to original payment method or wallet
FR-012 SHIP Track Order UC-09 High System shall provide real-time order tracking with carrier integration
