7. Security Design

7.1 Security Requirements Resolution

SRS RequirementDesign SolutionImplementation
NFR-003 Authentication JWT with short-lived access tokens RS256, 15min access + 7d refresh
NFR-004 Authorization Role-Based Access Control (RBAC) admin, staff, customer roles with permission matrix
NFR-005 Data encryption Encrypt sensitive data at rest and in transit AES-256 at rest, TLS 1.3 in transit

7.2 Data Security

Data TypeAt RestIn Transit
Passwordsbcrypt hashHTTPS
PIIAES-256 encryptionHTTPS
API TokensEncrypted storageHTTPS

7.3 Security Checklist

  • Input validation on all endpoints
  • SQL injection prevention (parameterized queries)
  • XSS prevention (output encoding)
  • CSRF protection (SameSite cookies)
  • Rate limiting per user/IP
  • Audit logging for sensitive operations
