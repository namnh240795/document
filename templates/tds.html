2.3 Key Design Decisions

#DecisionRationaleResolvesAlternatives
1Use Better Auth Handles session mgmt, token generation, credential verification out of the box FR-001 - FR-009 Passport.js, Auth0, custom
2PostgreSQL as primary database ACID compliance, JSON support, mature ecosystem DR-001 - DR-005 MySQL, MongoDB
3Drizzle ORM TypeScript-first, SQL-like API, lightweight, excellent PostgreSQL support DR-001 - DR-005 Prisma, TypeORM, Knex
4JWT access + refresh tokens Stateless access tokens for performance, refresh tokens for security NFR-004 Session-only, opaque tokens
5bcrypt for password hashing Industry standard, adaptive cost factor NFR-003 argon2, scrypt
6Redis for session cache + idempotency Fast lookup, TTL support for idempotency keys and rate limiting NFR-001, NFR-009, IR-004 In-memory, DB-only
7RabbitMQ for async verification Decouple API from email/SMS sending, retry via dead-letter queue NFR-010, NFR-011, IR-003 Kafka, AWS SQS, synchronous HTTP
8Dedicated SMS database (sms_db) Separate SMS audit logs from auth data, independent scaling DR-006, FR-012 Same DB, log files
9Idempotency via Redis keys Prevent duplicate verification sends within 5-min window NFR-009, FR-012, FR-013 Database uniqueness, application-level locks

7. Security Design

7.1 Security Requirements Resolution

SRS RequirementDesign SolutionImplementation
NFR-003 Password hashing bcrypt with 12 salt rounds Better Auth built-in
NFR-004 Token expiry Short-lived access + long-lived refresh Access: 15min, Refresh: 7d
NFR-005 Rate limiting Per-IP rate limiting on auth endpoints @nestjs/throttler
NFR-006 Data encryption TLS in transit, encrypted PII HTTPS + AES-256

7.2 Data Security

Data TypeAt RestIn Transit
Passwordsbcrypt hash (12 rounds)HTTPS
TokensEncrypted in DBHTTPS
PII (email, phone)Plaintext (indexed)HTTPS

7.3 Security Checklist

  • Input validation on all endpoints (class-validator)
  • SQL injection prevention (Drizzle parameterized queries)
  • XSS prevention (output encoding)
  • CSRF protection (SameSite cookies)
  • Rate limiting per IP (10 req/min for auth)
  • Audit logging for sensitive operations
  • Better Auth built-in security features
